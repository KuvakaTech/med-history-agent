Step 1 — Authenticate

Every route except /health needs a doctor JWT. The token is kept in localStorage and shared by all five pages, so log in once here. Access tokens last 15 minutes — if calls start returning 401, log in again.

The flow these pages walk

1 Login → 2 create a patient and give them a clinical profile (this is what gap alerts check against) → 3 run a live consult and watch gap_alert arrive → 4 find the finished session → 5 read the full record and correct it.

Steps 2–5 exercise Phase 2 Stage 0 (the read surface) and Stage 1 (2a, gap alerts). Coding, prescription and claims are not built yet, so there is nothing to test for those.
